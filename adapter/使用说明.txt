PCStory 直接下载测试 v0.1（Windows x64，无需 Python）

目的：输入游戏编号，直接向已运行的 PCStory 发送新增下载消息。
不需要服务器、登录精灵软件或抓包。

1. 先打开 PCStory，确认下载磁盘已配置好。
2. 双击 Start-Download.cmd，输入游戏 GID 后按回车。
   Roblox 的 GID 是 5131。建议选择未下载或已删除的测试任务。
3. 查看 PCStory 的下载列表，确认是否新增任务、显示下载速度。
4. 同目录的 pcstory-download.txt 会保存本次结果，可直接发送此文件。

如果 PCStory 以管理员运行，请右键 Start-Download.cmd，选择“以管理员身份运行”。
此测试仅支持已分析的 PCStory 6.4.2.0 二进制。文件名所在文件夹可能写着
6.2.0.1sp2，但实际 exe 是 6.4.2.0。程序会校验 SHA256，其他版本不会发送。
使用 PCStory 原有磁盘设置，不提供强制更新或任意磁盘参数。

CMD 调用：
PcstoryAdapter.exe --game-id 5131

可选参数：
--pid 9888                  多实例时指定 PCStory 的实际进程编号
--wait-seconds 60            等待新日志，范围 0 到 120 秒
--log-dir "D:\pcstory5.0\log" 显式指定实际日志目录
--output "D:\pcstory-result.txt" 指定本次结果文件（覆盖）

结果含义和退出码：
STARTED / 0：新日志显示此游戏开始下载，仍须核对真实速度；不是已下载完成。
ERROR / 1：未运行、版本不匹配、权限或文件错误。
ACCEPTED / 2：新日志显示新增任务成功，但尚未观察到开始下载。
FAILED / 3：新日志显示新增任务失败。
UNCONFIRMED / 4：消息返回，但未观察到此游戏的新增下载记录。
UNCERTAIN / 5：发送超时或窗口异常，结果不确定。先查下载列表，不要自动重发。

结果只检查命令发送后追加、且时间不早于本次发送的日志，旧日志改名也
不会被当作本次成功。日志格式须包含 PCStory 原生日期时间和毫秒。
输入错误会刷新结果文件，避免留下上次的成功结果。
Windows 自动化测试验证跨进程参数与结果识别，真实 PCStory 下载需要在
装有匹配版本和有效下载环境的测试机确认。

后续云端路径：网页选择网吧和 GID -> 对应 Agent 收到任务 -> 调用此 exe。
真实下载验证完成后，再接入云端；本版没有模拟进度。
