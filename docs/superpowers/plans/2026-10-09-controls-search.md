# 控制恢复与拼音搜索

目标：改善下载器忙碌时的暂停超时；同一网吧同一 GID 只显示最新任务；增加中文拼音首字母和全拼匹配，保留名称和 GID 原有匹配。

设计：保留任务与控制历史及独立的执行日志，合并仅作用于网页状态响应。原生菜单命令只发送一次，延长菜单等待时间；暂时读取失败不停止五分钟，发送异常后仍限时读取实际结果。绝不根据超时重发菜单。服务端使用 pypinyin 生成有界缓存的搜索键，所有发布方式安装同一依赖。
