# 网吧二级界面、连接稳定性和 Linux 服务端

用户已确认 Windows 本地真实下载成功。此次保留下载调用，调整网页使用流程并修复状态显示。

- 首页只展示网吧名称、连接状态、搜索及改名；进入网吧后输入游戏名或 GID，只返回匹配游戏和是否已下载，仍显示 PCStory 下载盘容量。
- 刷新不得先清空已显示结果；同数据不重建结果 DOM。异步响应绑定网吧和查询，旧响应或旧按钮不得作用于另一个网吧。
- 每 5 秒独立线程发送心跳，避免数据库读取或任务处理阻塞心跳；在线判断宽限 75 秒，库存有效期仍为 120 秒。心跳不反复保存完整库存。
- Windows 启动脚本和 EXE 控制台输出使用 UTF-8，日志继续 UTF-8。
- Linux CI 运行 API 测试、浏览器测试、Docker 构建、实际容器启动与重启持久化验证；输出 Linux 服务端包。Windows CI 重新打包 Agent 和测试服务端。
