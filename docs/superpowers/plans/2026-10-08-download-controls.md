# 下载实时信息与任务操作实施计划

目标：1 秒采集与网页刷新；显示 PCStory 下载列表全部原始字段与速度、更新量、剩余量；本地暂停和删除自动同步；网页可暂停、继续、删除任务及重新下载。

证据：当前两个 5 秒轮询叠加延迟，缺失行只报错且活动任务永久占用 GID。PCStory MENU 137 与消息表已确认 0x8016 暂停、0x8017 继续、0x8018 删除任务。处理函数依赖原生列表唯一选中行，而非 WPARAM GID。原有 0x468 同版本暂停分支只接受，不恢复，不能用作继续。

方案：保持下载入口，新增独立控制队列与持久化执行日志。Agent 读取控件 ID 1003，按 GID 唯一匹配，保存选中 GID，清除多选，设置目标选中；再次校验 GID 与唯一选中才发送下载页 WM_COMMAND。随后按 GID 恢复原选择并读取实际结果，失败或不确定不自动重发。删除只调用删除任务菜单，不调用删除游戏菜单。

任务不在有效下载列表中连续确认三次且至少两秒后显示已删除，解除重复任务锁；读取失败、无有效列表、不可解析目标行不能作为删除。刚 accepted 的任务给予启动宽限。完成仍以新库存已安装为准。暂停保存百分比但不显示 ETA；旧采样显示失效，速度不作为当前速度。
